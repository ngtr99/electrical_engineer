This project is a full-stack Django web application that showcases my work as an Electrical Engineer. I am building a dynamic portfolio platform where projects can be added, edited, viewed in detail, and deleted through a structured database system. The application is developed using Django’s MVC architecture, with models handling data storage, views managing business logic, and templates rendering dynamic content. It includes features such as image uploads, project detail pages, static file management, environment variable configuration, and deployment to Render using Gunicorn and Whitenoise. Through this project, I am strengthening my skills in backend development, database management, deployment workflows, and version control with Git and GitHub.
